PreTeXt lesson demo

Using exported lesson content inside CollabLearn

This is a lightweight stand-in for an exported PreTeXt lesson. The website treats it as lesson content while the surrounding app still handles discovery, auth, progress, and AI support.

What this proves

  • Modules can point at an exported lesson instead of inline editor HTML.
  • The viewer route can embed static educational content without rebuilding app logic.
  • PreTeXt can live beside the existing web stack rather than replacing it.

Recommended authoring flow

  1. Write lesson source in a dedicated PreTeXt content workspace.
  2. Export HTML from that workspace.
  3. Publish the HTML into a static path such as /pretext/<slug>.html.
  4. Create a module with contentType = pretext and point it to that URL.

Why this is the right boundary

CollabLearn already has strong application concerns: accounts, bookings, messaging, learning plans, and dashboards. PreTeXt is strongest when it owns structured lesson authoring, not platform behavior. This MVP keeps those responsibilities separate.
